The handoff Choosing is not the same as writing.

The idea is yours.
The result should be, too.

Playlist generation can blur a clear intention. A track gets substituted. An order shifts. A duplicate disappears.

Perfect Playlist starts after discovery. Search and Inspect help you choose. Build writes the exact Spotify track references you saved. The same local CLI works for people and AI agents.

Read the product principles ↗
One portable source

First, make the choice durable.

A TrackSequence is a plain ordered list of canonical Spotify URIs. It carries the selection from the moment you make it to the moment Spotify receives it.
